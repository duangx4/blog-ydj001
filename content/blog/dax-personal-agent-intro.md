## What · DAX 是什么

**一句话：DAX 是我（颜当峻）自建、跑在自己设备上的个人 AI Agent 系统——一个会记住我、会自己定时干活、会区分「哪个模型便宜/哪个负责难活」的管家。**

如果只用一个比喻，我会说：**它是住在我自己设备里的一支「管家团」——有大脑、有手脚、有住址、还有家规。** 不是某个大模型的套壳，也不是租来的在线助手；它是在「能聊天的模型」外面，又长出了「能记住、能干活、能自律」的一整套组织。

### 把它拆成三层看

DAX 再大，也就三样东西叠在一起：**软件层（怎么想、怎么干）· 硬件层（住在哪）· 约束层（家规是什么）**。这张图就是它的全景：

{{< figure src="dax-architecture-complete.svg" alt="DAX 完整分层架构" caption="DAX 全景：①软件层·入口 ②大脑+模型通道 ③应用与服务｜④硬件层·五台设备｜⑤约束·规矩" >}}

**软件层 = 一个人怎么想、怎么干**，分三段：

- **① 入口（耳朵和嘴）**：它从哪听你说话——手机/平板、平时对话、QQ 都能喊它；还有一道「挑活标准」把关，只接一眼能看出好坏的活，不接说不清的活。
- **② 大脑 + 模型通道（怎么思考）**：大脑（AI 管家）负责想事和分派；模型通道负责「调哪个脑子」——简单活用便宜的 flash，难活升到 earth，官方 DeepSeek 只做兜底。会省钱，也不会卡死。
- **③ 应用与服务（手脚和工位）**：一半跑在云端（云端 agent、Open WebUI 界面、知识库、QQ 机器人），一半跑在本地（Gateway 主代理、HUD 控制台、个人工作台）。云端和本地用 frp 隧道 + 每小时同步分工：**重活上云，敏感数据留本地**。

**硬件层 = 住哪几套房**，五台设备各管一摊：

| 硬件 | 比喻 | 干什么 |
|------|------|--------|
| 💻 本机 Windows | 书房·创作大本营 | 数据权威在这；AI 管家主账号；23:30 停电关机前自动备份 |
| ☁️ 2号机 doge | 24 小时值班室 | 云端大脑；7×24 在线、断电自启、每小时备份 |
| 🌐 1号机 香港 | 家门口的门房 | nginx + frps + SSL；域名 ydj001.xyz 都经它，三端互通 |
| 📱 手机/平板 | 随身电话 | 收提醒、写笔记、问答；只连云端，不直连本地 |
| 🗄️ 枣庄机 | 保险柜·备份 | 异地备份；0号机退役中，资产迁出 |

**约束层 = 家规**：停电自我保护（23:00 备份 → 23:30 离线，云端照常）、安全红线（只记真事、密码不存、可回退）、数据主权（账本等敏感数据只留本机）。

一句话收束：**移动端负责访问，云端负责跑重活，本地负责守住数据，1号机负责把它们连起来；家规负责不让它跑偏。**

### 名字从哪来

DAX = **DangJun + Agent eXecutor**。

- **DangJun（当峻）**：我的名字嵌进去，这是「只服务我一个人」的系统
- **Agent eXecutor**：点题它做的事——不只是回答你，而是**执行**

（候选名淘汰了一堆：Yan's Life Manager 太窄、SHILI 太安全、ADA/MAX/HALO 没梗，最后 DAX 胜出。）

## Why · 为什么做 DAX

市面上现成的 AI 助手一大堆，为什么花这么大力气自己搭一套？因为通用助手有三个我解决不了的问题：

### 1. 通用助手「不记得我」

跟 ChatGPT 聊天是一段一段的，关掉就忘。而我的 DAX 有**持久记忆**——`memory/` 里每天一篇日志，昨天的决策、踩过的坑、立下的 flag，今天还能翻出来。它记得我是电气专业、要考电网、在搭 MC 服务器。

### 2. 通用助手「只动嘴，不干活」

通用助手顶多帮你写段话。我的 DAX 能**真的执行**：定时跑自主任务、用 CDP 抓网页数据、控制 LED 状态灯、调服务器、跨设备同步。它从「能聊天」升级成「能干活」。

### 3. 数据主权不扩散 + 成本可控

- **主权**：我的账本、待办、成绩这类敏感数据**留在本地机**，不随同步扩散到不需要它的机器（比如云端那台只跑公开场）。
- **成本**：多模型通道自己挑——简单活用便宜的 flash，难活升到 earth，官方 DeepSeek 只做兜底。一个月下来省 96% 的 API 费。

**核心动机其实是：我想看 AGI 长什么样——从「造一个为我服务的 Agent」的角度，而不是「等别人造好卖给我」。**

## How · DAX 怎么运作

运作是一个五步流水线：**喂料 → 大脑 → 记忆 → 执行 → 审计**。

{{< figure src="dax-how-it-works.svg" alt="DAX 运作流水线" caption="DAX 运作：喂料 → 大脑 → 记忆 → 执行 → 审计" >}}

### 1. 喂料 / 输入
- 对话指令：QQ、Web 控制台、HUD 都能喊它
- 每日自主任务：Windows 计划任务定时触发，它自己回顾记忆 → 查待办 → 提想法 → 落地
- 待办 / 笔记 / 队列项

### 2. 大脑（Agent 引擎）
以 **OpenClaw Gateway** 为底座，做三件事：
- **多模型路由 + 自动降级**：主模型限流/出错时，自动切到 fallback，系统不打不开
- **真调工具**：不是光输出文字，而是真的调用工具去执行（这是「能干活」的关键）

### 3. 记忆
- `memory/YYYY-MM-DD.md` 每日日志 = 我的「录像带」
- `memory_search` 语义检索，它能想起很久以前的事
- RAG 知识库（云端，embeddings 存向量）

### 4. 执行工具链
「做完没」一眼能看出来的活，它才接：HUD 控制台、CDP 抓数据、LED 状态灯、文件/服务器、通知/计划任务。**验收点明确、干完能验证**——这是挑活的标准，也是 DAX 不变成「万能打杂工具」的原因。

### 5. 审计 & 约束（红线）
- **只记真实，绝不代编**：空状态 = 没有证据，不是进度为零
- **凭据绝不过手**：token 只记存在性/后四位/哈希
- **外网只认自家域名**（ydj001.xyz 系），防止骗子冒充
- **改重要配置先问**：重大变更要你点头才动

每一步操作都写进 OOS 状态账本（op + 审计日志），可回看、可复盘。

## 小结

DAX 的定位不是「又一个聊天机器人」，而是一个**拥有记忆、能执行、守住数据主权、成本可控的个人 Agent 系统**。

它强不强？强。但它是不是 AGI？这篇只回答了它「是什么、为什么、怎么跑」——**下一篇**，我们来聊聊它跟「通用智能」的真正差距在哪。
