## 一句话说清 DAX

**DAX 是我自建、跑在自己设备上的个人 AI Agent 系统**——一个会记住我、会自己定时干活、会区分「哪个模型便宜、哪个负责难活」的管家。

它不是某个大模型的套壳，也不是租来的在线助手。它是在「能聊天的模型」外面，又长出了「能记住、能干活、能自律」的一整套组织。用比喻说，它是一支住在我自己设备里的管家团：有大脑、有手脚、有住址、还有家规。

## 它长什么样

DAX 再大，也就三样东西叠在一起：**软件层（怎么想、怎么干）、硬件层（住在哪）、约束层（家规是什么）**。

{{< archify src="/archify/dax-architecture.html" caption="DAX 全景：①软件层·入口 ②大脑+模型通道 ③应用与服务｜④硬件层·四台设备｜⑤约束·规矩" >}}

**软件层**分三段：

- **入口**：手机、平板、QQ、网页控制台都能喊它。但有一道「挑活标准」把关：只接做完一眼能看出好坏的活，说不清验收标准的先问清楚。
- **大脑 + 模型通道**：大脑负责想事和分派；模型通道负责挑「用哪个脑子」——简单活走便宜的 flash，难活升到大模型，再留一条官方通道兜底。
- **应用与服务**：一半在云端（agent、WebUI 界面、知识库、QQ 机器人），一半在本地（主代理、HUD 控制台、个人工作台）。两边用 frp 隧道连起来，重活上云、敏感数据留本地。

**硬件层**是四台设备，各管一摊：

| 硬件 | 干什么 |
|---|---|
| 本机 Windows | 数据和创作的大本营；AI 管家的主账号；关机前自动备份 |
| 服务器 doge | 24 小时值班室；7×24 在线、断电自启、每小时备份 |
| 香港 VPS | 家门口的门房；nginx 反代 + 内网穿透，所有域名都经它进出 |
| 手机 / 平板 | 随身终端；收提醒、记笔记、问问题，只连云端 |

**约束层是家规**：关机前的自我保护、安全红线（只记真事、凭据不进消息和日志、改重要配置先问）、数据主权（账本这类敏感数据只留本机）。

一句话收束：**移动端负责访问，服务器负责跑重活，本机负责守住数据，香港 VPS 负责把它们连起来，家规负责不让它跑偏。**

### 名字从哪来

DAX = **D + Agent eXecutor**。D 是我名字里的一个字母，标出「只服务我一个人」；Agent eXecutor 点题它做的事——不只是回答你，而是执行。

候选名淘汰了一堆：Yan's Life Manager 太窄，SHILI 太安全，ADA、MAX、HALO 没梗，最后 DAX 胜出。

## 为什么要自己搭

现成的 AI 助手一大堆，为什么花这个力气？因为通用助手有三个我绕不过去的问题。

**它不记得我。** 跟 ChatGPT 聊天是一段一段的，关掉就忘。DAX 有持久记忆：每天的日志、踩过的坑、立下的计划，隔了几个月还能翻出来。它记得我是电气专业、在做机器人竞赛、在搭 Minecraft 服务器。

**它只动嘴，不干活。** 通用助手顶多帮你写段话。DAX 能真的执行：定时跑任务、抓网页数据、控服务器、跨设备同步。从「能聊天」升级成「能干活」。

**数据和成本得握在自己手里。** 账本、待办、成绩这类东西留在本机，不随同步扩散到不需要它的机器上。多模型通道自己挑，简单活用便宜的，一个月下来省掉大部分 API 费用。

但说到底，真正的动机是：**我想看 AGI 长什么样，从一个「造一个为我服务的 Agent」的角度，而不是等别人造好卖给我。**

## 它怎么运转

运转是一条五步流水线：**喂料 → 大脑 → 记忆 → 执行 → 审计**。

{{< archify src="/archify/dax-how-it-works.html" caption="DAX 运作：喂料 → 大脑 → 记忆 → 执行 → 审计" >}}

**喂料**：对话指令从 QQ、网页控制台、HUD 进来；也有定时触发的自主任务，它会自己去回顾记忆、查待办、提想法。

**大脑**：做两件事——多模型路由（主通道限流或报错时自动切备用，系统不会打不开）和真调工具（不是光吐文字，而是真的去执行）。

**记忆**：每天的日志相当于它的录像带，配合语义检索能想起很久以前的事；再加上一个云端知识库做向量召回。

**执行**：它只接「做完能验证」的活——控制台、抓数据、文件和服务操作、定时任务。验收点明确，是它挑活的标准，也是它没变成万能打杂工具的原因。

**审计与约束**：只记真实，不代编（空状态等于没有证据，不等于进度为零）；凭据不过手（只记存在性和后四位）；改重要配置先问；每一步都写进状态账本，可回看、可复盘。

## 那它算 AGI 吗

**不算。** DAX 是一个相当强的通用任务 Agent，但不是 AGI。这两个名字只差一个词，本质差一层。

判断标准不是「它能回答多少问题、干多少活」，而是看三个核心能力的边界。

{{< archify src="/archify/dax-not-agi-gap.html" caption="通用智能三要素：跨域泛化 · 自主目标 · 持续学习 —— DAX 差的三道坎" >}}

**跨域泛化**。真正的通用智能遇到全新领域，能边学边做，把别的领域的经验迁移过去。DAX 只在「语言理解」和「训练时见过的工具调用」里强。换到完全没见过的领域，它没有自我学习的机制——参数是训练时定死的，不会因为我用得多就变聪明。它很博学，但那是别人教出来的，不是自己摸索出来的。

**自主目标**。通用智能有内在动机，会自己冒出「我想做这个」。DAX 的目标全靠人喂。看着最像自主的那个每日任务，其实也是定时器触发的一个脚本——是定时器叫人干活，不是它自己想干了。它不会有一天自己说「你最近总错过高铁，我帮你做个提醒吧」。

**持续学习**。DAX 靠三样东西假装记得：每日日志、语义检索、云端知识库。它确实能想起以前的事，但那是查数据库查出来的，不是长在脑子里的。记忆是外挂的档案库，不是内生的经历。删掉这些文件，它就回到出厂状态。

### 为什么它看起来那么像

因为 DAX 把「能干活」做到了一流：多模型路由、真调工具、持久记忆、自主定时、成本优化。给人的错觉是「它好全能，跟人一样」。

这里有个关键的偷换：**工具的效能不等于智能本身。**

> 通用智能是「能自己决定今天出门干嘛的人」；
> DAX 是「一个认得全天下菜的顶级厨师」。
>
> 再厉害的厨师，也得有人告诉他今天做哪道菜。能不能自己决定做哪道菜，才是智能的边界。

### 它到底算什么

如果把智能程度排一条线：

```
┌──────────┐   ┌──────────────────┐   ┌─────────────┐
│ 专用助手   │ → │ 通用任务 Agent      │ → │     AGI     │
│ (ChatGPT) │   │ (DAX / Claude等)  │   │ (颠覆式通用)  │
└──────────┘   └──────────────────┘   └─────────────┘
  只会聊           能干活·能组合工具      能自主·能持续学习
```

DAX 站在第二格的顶尖，是这个品类的强者。它离第三格差的不是多装几个工具，而是三个架构级的东西：真跨域学习、真自主意愿、真连续经验。这些堆功能堆不出来。

## 写在最后

DAX 的定位不是又一个聊天机器人，而是一个有记忆、能执行、守住数据主权、成本可控的个人 Agent 系统。它是通用任务代理，不是通用智能。

不过有意思的地方在于：我现在做的很多事——持久记忆、多模型路由、状态账本、审计约束——恰恰是在往那三道坎的方向修路，虽然修得很慢。**造的过程，比「它是不是 AGI」这个标签更有意思。**
